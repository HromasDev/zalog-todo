# Todo App (React + TypeScript + Vite)

Интерактивное приложение списка задач (To-Do List) с сохранением состояния в `localStorage`, фильтрацией и возможностью редактирования.

## Стек технологий
- **Фреймворк:** React
- **Сборщик:** Vite
- **Язык:** TypeScript
- **Стилизация:** Tailwind CSS
- **Хранение данных:** LocalStorage API

## Функционал
- Добавление, редактирование и удаление задач
- Переключение статуса выполнения (завершено / активно)
- Фильтрация задач (`Все`, `Активные`, `Завершенные`)
- Очистка завершенных задач в один клик
- Подсчет прогресса выполнения задач
- Сохранение состояния при перезагрузке страницы

## Инструкция по запуску

### 1. Клонирование репозитория
\`\`\`bash
git clone https://github.com/hromasdev/zalog-todo.git
cd zalog-todo
\`\`\`

### 2. Установка зависимостей
\`\`\`bash
npm install
\`\`\`

### 3. Запуск в режиме разработки
\`\`\`bash
npm run dev
\`\`\`
Приложение будет доступно по адресу: [http://localhost:5173](http://localhost:5173).

### 4. Сборка проекта для продакшена
\`\`\`bash
npm run build
\`\`\`
